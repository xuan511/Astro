# 展示层设计规范

2026-11-18，参照 XHBlogs 改为卡片矩阵与毛玻璃展示，保留拾间的薄荷绿重点色、中文阅读、技术/生活栏目、已有内容和持久音乐。新增背景选择与首页精选手动切换，没有新增依赖、客户端框架、后台或内容栏目。参考与许可见 [XHBlogs 改版说明](XHBLOGS-REFERENCE.md)。

首页采用搜索、个人名片与音乐卡、精选海报与随记/外观、最近文章、项目的顺序。海边背景为新绘插画；表面分为半透明玻璃与更实的阅读底色。桌面导航为 sticky 胶囊，页面锚点统一预留 104px。保留已合并性能 PR 的 0ms 离场 / 120ms 进入与 2px 位移，不恢复较慢转场。以下 wdxtub 观察为 2026-11-13 的历史研究依据，不是此次截图结果。

## 参考依据

实际查看 [wdxtub 首页](https://wdxtub.com/)、[博客列表](https://wdxtub.com/blog)、[CSAPP 系列](https://wdxtub.com/series/csapp) 和 [长文章](https://wdxtub.com/blog/csapp/thin-csapp-0)。在 1363×900 的浏览器中读取渲染布局：主区域最大 1024px、左右内边距 24px；文章为 720px 正文、208px 目录、48px 间距；正文约 17px / 31.45px，文章标题 30px / 36px，页头约 56.8px。

由此借鉴的是紧凑页头、有限正文宽度、正文与目录分工、节制的列表与清楚的标题层级。以上是渲染页面的观察，不据此断言参考站的完整框架、后端或源码架构。参考站实际显示为深色，截图按实际主题记录，没有把按钮文字当作主题证据。未复制其个人内容、品牌和整套样式；也没有请求此前禁止访问的 SWUST MC 域名、子域、资源或 API。

## 设计变量与所有权

源头为 `src/styles/tokens.css`，常用值如下。组件应按语义使用变量，只有确有局部需求时增加私有值，避免每页重新定义相同尺度。

| 类别 | 规则                                                                                                                                                      |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 颜色 | `bg / paper / text / body / muted / line / accent / soft` 与 `glass / glass-edge / reading-paper`；深色覆盖同名语义变量，保留薄荷绿重点色并增加蓝灰层次。 |
| 字体 | 中文系统无衬线、生活正文衬线、代码等宽；不新增远程字体请求。                                                                                              |
| 字号 | 12、14、16、18、22、28px 基础层级；阅读字号保留 16 / 18 / 20px。正文行高 1.95，辅助正文 1.85。                                                            |
| 间距 | 4、8、12、16、24、32、48、64、96px；页面侧边距 `clamp(18px, 3vw, 32px)`。                                                                                 |
| 容器 | 全站壳 1088px，普通内容 960px，阅读 704px、宽阅读 816px，目录 208px、正文间距 48px。均受视口与侧边距限制。                                                |
| 控件 | 44px 最小操作高度；基础圆角 6 / 8 / 12px，主卡片 24px；控件动效 140 / 220ms、页面进入 120ms，沿用减少动画偏好。                                           |

`Base` 管理全站壳、导航、页脚、搜索、外观和唯一播放器；`PostLayout` 管理文章展示；`PostIndex` 管理栏目/分类/标签列表；`PageHeading`、`PostCard`、`TocLinks`、按钮和元信息规则负责复用。`HomeMusic` 复用 Player 的控件钩子，`HomeSpotlight` 仅增强当前页。全局外观由 Appearance 持有，页面不建立新音频实例。

`tokens.css` 拥有所有语义颜色与尺度；`global.css` 拥有基础控件；`shell.css` 拥有悬浮页头、页脚、全站背景与外观面板；`home.css` 只由首页导入。全屏背景不做持续动画；仅玻璃卡片和导航使用有限 backdrop-filter，可切换为实色表面。

## 响应式关系

- 页头在 832px 及以下使用菜单，833px 起显示桌面导航；脚本监听与 CSS 使用同一边界。
- 首页主矩阵在 960px 以上为 7/5 分栏，705–960px 为等宽两列，704px 及以下单列；手机继续显示音乐卡、随记和外观选择。
- 文章在 1040px 及以下使用正文内可折叠目录；1041px 起显示侧目录。宽阅读按钮只在 1089px 起显示，避免出现点击后没有宽度变化的控件。
- 列表/关于侧栏在窄屏回到文档流；随记根据可用宽度自动分列。标题、标签、英文长串允许换行，Grid 子项设置最小宽度边界。
- 浮层使用视口高度约束和内部滚动。手机播放器控件分行；错误信息与进度展开均有底部留白。

断点以 CSS px 为准。浏览器缩放/视口模拟可能有像素取整，应记录实际 `innerWidth`，不只记录工具请求值。

## 状态与回归约束

链接、按钮与输入提供可见 focus；选中搜索范围同时使用勾选、边框和文本，禁用控件保持明确状态。搜索有载入、无结果、格式错误和重试入口；播放器错误有可见原因和重试操作。深色模式继续使用相同组件层级。

原生弹层继续由共享控制器管理互斥、Escape、背景点击、滚动锁和关闭后焦点。样式调整不得替换 dialog 语义，不得改变快捷搜索的当前文章 URL。播放器 DOM 与控制器本轮未改，样式修改仍需验证实际音频实例、暂停状态和时间推进。

`verify-presentation` 负责结构契约，浏览器负责视觉关系。长标题、无封面、索引故障和音频故障使用独立的本地成品副本，不向生产源码加入 QA 页面或假数据。

实际响应式、键盘、错误恢复、Lighthouse 和部署结果见 [阶段验收](ACCEPTANCE.md)。截图、原始测量和完整源码放在本轮交付目录；本机模拟不能代替实体手机、软键盘和屏幕阅读器验收。

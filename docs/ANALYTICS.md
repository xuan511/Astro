# 访问统计与 ATRI 主题

2026-11-28。本轮基于最新仓库 `4c84679694d605ad07d693fab16db0a1f8b13d6d`，保留 Qing Notes 站名、SEO 验证配置、12 篇文章、资源下载和 5 首完整音乐。

## 统计在哪里

文章标题下显示当前文章的「阅读 N 次」；普通页面右侧「小站足迹」和页脚显示累计访问 / 访客，进入 `/stats/` 可查看累计 PV、累计访客、今日 PV、今日访客和真实内容分类数量。

阅读量是页面打开次数。滚动、展开目录、修改字体或操作播放器不重复计数；阅读后的再次访问和刷新会增加 PV。统计从接入后开始累计，不追溯未采集的历史，不虚构趋势、来源榜或文章排行。分类分布来自 Content Collections，与访问统计独立。

## 服务与数据

选用 [不蒜子文档](https://www.busuanzi.cc/doc.php) 公共累计服务，接口格式依据其 [3.6.9 官方客户端](https://cdn.busuanzi.cc/busuanzi/3.6.9/busuanzi.min.js)。本站自行实现小型 fetch 适配，不下载或执行其第三方统计脚本，统计功能没有新增运行时依赖。正式域名已用一次真实接入请求验证 HTTP 200、跨域允许和六项计数响应。

请求发往 `https://cdn.busuanzi.cc/api.php`，POST body 只包含规范化的公开页面 URL 和空 referrer。使用 `credentials: omit`、`referrerPolicy: no-referrer`，不发送搜索词、query、hash、完整来源页或点击事件。服务仍会接收请求连接信息，以便累计与去重。本站没有为统计创建本地身份标记或写入浏览器计数。

服务按域名聚合站点数据，同一 GitHub Pages 域名的其他项目可能合并在全站总计；文章路径仍区分 `/Astro/`。访客数是服务估算值，不等于精确真人数量。今日数据按服务每日重置规则计算；本服务不提供本项目的私有分析后台或历史报表，亦未承诺 SLA 或永久保存。

维护配置在 `src/config/analytics.ts`，包括总开关、接口、接入日期与 10 秒超时。迁移域名或改用自建统计时应核对供应商条件和响应字段，再调整适配层。当前公开域名符合该服务的域名限制。

## 生命周期与故障

`Analytics.astro` 只输出当前部署配置，`analytics.ts` 保持一个统计控制器：

1. 在成功页面加载后等待浏览器空闲，后台页面等到真正可见再请求。
2. 同一次导航只上报一次，不监听或改写 pushState；初次模块执行与 Astro page-load 不会双报。
3. 使用 origin + pathname 合并带查询和锚点的分享链接。仅统计同源、正确部署前缀的 HTTPS 页面，跳过本地、IP 与 noindex 工具页。
4. 换页取消未发送任务与旧响应；旧文章的返回值不会覆盖新文章。
5. JSON 必须包含完整、非负、安全整数计数，界面使用 textContent；不执行服务返回内容。
6. 失败或超时显示「— / 统计暂不可用」，不回退到假 0，不自动重试或轮询，避免请求已计数而重试造成虚增。正文和播放器不依赖统计成功。

当前服务没有公开的卡片批量只读接口，因此只在正在阅读的文章显示该页阅读量，避免为首页每张卡片发计数请求。站点多个计数展示共用同一次响应，没有 N+1 请求。

## 主题与性能

组件配色统一为 ATRI 启发的海蓝、银白与少量珊瑚色：导航、文章卡、分类、搜索、弹窗、播放器、统计卡和角色共用语义 token。保留亮 / 暗 / 系统、字体、背景与色相配置。

默认色相由 165° 调整为 205°。旧版本恰好保存默认 165° 的偏好自动迁移；其他色相继续保留。新版本带 paletteVersion=2 的 165° 是明确选择，不再迁移。仅保留亚托莉，详细来源与交互见 [角色说明](COMPANIONS.md)。

性能改动：

- 删除六个退休角色 WebP，合计 199,126 字节，移除选择网格和六组专属性格数据。
- 首页横幅生成 800px / 1280px WebP：29,382 / 50,342 B，相比 112,610 B 原图分别减少约 74% / 55%。使用 Sharp 0.35.5，resize 保持比例、quality=72、effort=5；没有改变图像内容。
- 文章和其他次级页使用 CSS 海浪横幅，不请求大装饰图。全屏壁纸只在对应模式和海边画面真正启用时才作为 CSS 背景加载。
- 默认列表 / 网格不创建 ResizeObserver、不排 JS 布局帧。瀑布流启用时才观察卡片，离开即释放；测试验证观察器和定位样式的生命周期。
- 普通卡片取消多层 backdrop blur；全屏壁纸模式只保留必要的顶栏模糊。动画继续遵守减少动作。
- 统计请求在正文之后进行，有超时且不阻塞路由。音乐仍是单一 audio，首屏不自动下载完整歌曲。

最终成品与 Pages 根路径 / 子路径 / 自定义域名核对结果、远端部署、实测截图和源码哈希见交付验收报告。性能结论以具体资源与工作量减少为依据，不把本机导航时间当作所有设备的速度或帧率承诺。

# 阅读与查找体验 · v3.1.0

本轮沿用拾间的浅绿纸面、中文阅读排版与生活/技术双栏目，重点减少查找、阅读和翻页时的打断。

## 2026-10-28 · 项目速览与条件明确的搜索

- 搜索范围升级为可见按钮，文字与勾选标记共同表达选中状态。关键词、范围分别显示为可移除条件；移除关键词保留范围，移除范围保留关键词，“清除全部”重置两者。建议词沿用当前范围。
- 项目 ID 作为补充匹配字段，结果中显示 ID 并安全高亮；标题与元数据的匹配仍比 ID 和正文优先。原有中文合成、防抖失效、索引重试和键盘选择继续复用。
- 项目卡片保持完整详情主链接，新增“快速了解”入口；速览只展示同一份项目数据中的摘要、真实状态、技术栈和关键链接。没有添加重复项目清单或伪造截图。
- 桌面速览使用右侧原生 dialog，手机改为全宽，提供明确关闭入口、滚动区域和安全区；Esc/关闭后恢复入口焦点，导航前关闭并清理旧监听，返回卡片页后重新初始化。与其他原生弹层互斥。
- JavaScript 不可用时预览按钮隐藏、独立详情保留，搜索显示原生范围 select 和归档回退说明。主要操作采用 44px 触控高度，范围按钮在窄屏分两列。

在生产预览实测了根路径与 `/Astro/` 的搜索、预览、完整详情和音乐连续播放，检查了 320/390/768/1440px。原有播放器未改动，详情预览和跨页跳转仍使用同一音频实例。真实手机软键盘与屏幕阅读器不在本次实测范围。

交互思路来自公开仓库中 [MC Wiki 的图鉴页面](https://github.com/mcyudream/yudream-admin-plugins/blob/f6e3177de65a77787f36ead14fde04cb35d2663f/yudream-frontend/packages/plugin-mc-wiki/src/pages/Items.vue) 的检索与详情展开；本轮没有请求参考站域名、图片或 API，没有复制其组件或导入整套管理平台。Astro 和静态托管方案保持不变。

## 2026-10-27 · 维护修复

保留已有页面、内容、原生对话框与播放器持久节点，只修复实际复现的边界：

- 输入变化或开始中文合成时立即作废旧搜索请求并移除过期结果；180ms 防抖期间不再出现与输入框不一致的旧结果。共享索引先校验字段与站内 URL 再缓存，格式错误可重新载入。
- 歌曲 ID 失效时清零关联进度；同一首音频失败后可主动重新加载，迷你条提供可见重试说明，手机底部计入安全区。
- 浅色软底上的辅助文字原对比度为 4.36:1。统一微调 `--muted`，改善手机目录和选中歌单项的小字阅读，不改变原有色彩层次。

实际执行客户端脚本的 Node 回归测试覆盖异步竞态、中文合成、离页清理、错误索引重试、用户触发播放和错误音源恢复；另在生产预览浏览器中验证实际音频实例和时间推进。测试服务单独模拟首次索引结构错误及音频 503，重试后恢复，不向源码添加故障页面或假歌曲。

本轮查阅 [Astro 客户端导航与生命周期](https://docs.astro.build/en/guides/view-transitions/) 与 [GitHub Pages 部署](https://docs.astro.build/en/guides/deploy/github/)，核对持久节点、导航清理以及 `site`/`base` 的用法。没有导入社区主题或新增依赖。详细结果和未验证范围见 [阶段验收的最新记录](ACCEPTANCE.md)。下文保留 v3.1.0 的设计说明与历史验收背景。

## 使用方法

### 快捷搜索

点击导航栏的搜索图标，或按 `Ctrl K`（Mac 为 `⌘ K`）。非输入状态下也可以按 `/`。弹窗打开后输入框自动取得焦点；输入中文时等待输入法组合完成，不按中间拼音反复搜索。

匹配标题、正文、标签、分类和项目，多个关键词按“全部包含”匹配。标题和摘要里的命中词高亮。可选择技术、生活或项目范围；无关键词时提供来自已发布文章的标签建议。

在输入框按 ↓ 进入结果，↑ 返回输入框，Enter 打开链接，Esc 退出。弹窗最多显示六项，点击“在搜索页查看全部结果”进入完整列表。完整列表按每批二十项继续展示，查询和范围保留在网址中。

快捷搜索不会改写正在阅读的文章网址，也不会停止音频。索引首次有查询时才请求，同一会话内共享；读取失败提供重新载入按钮。没有 JavaScript 时，搜索入口仍能进入搜索说明页并找到归档。

### 阅读设置与目录

文章顶部的 A− / A＋ 在 16、18、20px 三档之间切换；“宽屏阅读”在桌面扩展正文列。默认 18px；生活文章继续使用衬线字体。移动端按视口自适应，不显示无意义的宽度开关。

字号和宽度只保存在当前浏览器，不上传。刷新或换篇后继续使用；存储不可用时，当次页面仍可调节。发布为不同域名或不同子路径后，浏览器会使用该站点自己的偏好。

手机目录固定在正文阅读区域顶部，显示当前位置。展开后选择章节，目录自动收起，标题在目录下方留出间距。章节旁的 `#` 是原生片段链接，可用于分享某一节；“复制链接”会包含当前网址中的章节位置。

### 图片、代码与表格

点击有描述文字的正文图片或生活封面，打开图片查看器。支持关闭按钮、Esc 和点击背景退出，原生对话框恢复图片按钮焦点。链接中的图片不会被改造成另一个按钮；装饰性空 alt 图片不增强。

大图使用浏览器已加载的图片资源，不虚构更高分辨率。当前生活文章封面是明确标记的示例插画。加入真实照片时请提供准确 alt，并按写作指南压缩与管理资源。

代码块新增语言提示，复制操作有成功/失败反馈。代码与表格可用 Tab 取得焦点，通过方向键横向滚动，表格保留原有行列语义。

## 自行验收

1. `npm ci`、`npm run dev`；在首页按 Ctrl/⌘ K，输入 Linux，检查高亮；用 ↓、Enter 打开结果，再试空状态、清空和标签建议。
2. 直接打开 `/search/?q=Linux&kind=project`，确认独立搜索结果和快捷搜索一致。搜索时输入 `/` 应正常进入输入框，不重新打开弹窗。
3. 打开技术文章，调大字号、打开宽屏，进入生活文章并刷新，确认偏好保留。复制文章和章节链接，核对地址。
4. 手机或窄视口展开目录，选择“公式与组件示例”，确认自动收起、章节不被遮住、当前位置正确；来回滚动检查高亮。
5. 点击生活示例封面，按 Esc 退出，继续 Tab，确认焦点回到图片按钮。加入自己的 Markdown 照片后测试正文图片。
6. 用 Tab 聚焦代码和表格并横向滚动；复制代码、粘贴到文本文件，确认没有复制到语言提示与按钮文字。
7. 手机展开导航、Tab 到链接后按 Esc，确认菜单关闭且焦点回到菜单按钮。分别检查深色与浅色。
8. 手动播放音乐，再用快捷搜索打开另一篇文章，确认声音和播放进度继续；刷新应不自动播放。
9. 执行 `npm run verify`、`npm run verify:pages -- --repo=xuan511/xuan511.github.io`；按部署文档发布。

本轮浏览器检查使用桌面和 390/820px 的同源 iframe 视口（可用内容宽度约 375/805px），不能替代真实手机、屏幕阅读器、软键盘和 Windows 真机验收。Lighthouse 本轮没有实测分数；参见部署文档中的手动工作流。

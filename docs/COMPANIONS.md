# 亚托莉陪伴

2026-11-28 起只保留 ATRI 的亚托莉。其余六位角色的目录、选择界面、专属回应数据和 WebP 素材已移除；旧浏览器保存的角色 id 会自动回退到亚托莉，保留位置、隐藏、收起与安静偏好。

## 使用

- 点击角色：弹跳、欢呼、转圈、轻摇、点头；连点三下有星光和爱心彩蛋。
- 点爱心或长按约半秒：摸摸头。拖动超过阈值会取消长按，避免误触。
- 拖动调整位置，方向键移动，Home 复位；角色会避让播放器。
- 星星按钮打开陪伴设置，可安静陪伴、复位或隐藏。收起后点小圆钮展开，隐藏后从页脚「亚托莉」恢复。
- 手机首次访问默认收起。偏好按部署路径保存在浏览器；存储不可用时当前会话仍可用。

角色、外观面板和播放器都沿用持久节点。站内换页关闭弹窗、清理临时气泡和动画；支持 Esc、焦点恢复与弹窗互斥。角色只在互动或实际音乐播放时动作，后台、安静模式、系统减少动作时停止。Web Animations API 不可用时保留文字回应，不加载 Live2D、角色 SDK 或聊天服务。

## 素材来源

亚托莉图来自此前核对的 [ATRI 动画官方小游戏](https://atri-anime.com/special/adventure/) 的 [透明 SD 图](https://atri-anime.com/assets/img/special/adventure/header/header_atri.png)，经缩放与透明留白整理编码为本地 WebP，20,922 字节。角色权利归原权利人，不表示官方合作或商业授权。本站鼓励台词为原创，不冒充原作对白。

本次只精简角色范围，没有重新绘制该角色。图片仅在本站本地发布，不依赖图片热链；只有一个角色来源，三个展示入口共用同一缓存资源。

## 维护边界

- `companions.json`：只含 `atri`，构建成品检查会拒绝其他 id。
- `companion-state.ts`：数据与偏好验证、旧 id 回退、位置与播放器避让。
- `companion-reactions.ts` / `companion-motion.ts`：有限关键帧、连击与取消；粒子最多 12 个，不叠加旧批次。
- `companion.ts`：一个持久控制器，位置只在拖动、尺寸变化和复位时更新。
- `Companion.astro`：角色、收起按钮与陪伴设置；无脚本时隐藏挂件，保留正文访问。
- 测试覆盖唯一角色、损坏偏好、旧角色迁移、动作取消、减少动作与窄屏避让；成品检查逐页验证资源路径与唯一实例。

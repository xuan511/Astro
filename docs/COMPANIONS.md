# 亚托莉陪伴

2026-11-28 起只保留 ATRI 的亚托莉。其余六位角色的目录、选择界面、专属回应数据和 WebP 素材已移除；旧浏览器保存的角色 id 会自动回退到亚托莉，保留位置、隐藏、收起与安静偏好。

## 使用

- 点击角色：弹跳、欢呼、转圈、轻摇、点头；连点三下有星光和爱心彩蛋。
- 点爱心或长按约半秒：摸摸头。拖动超过阈值会取消长按，避免误触。
- 拖动调整位置，方向键移动，Home 复位；角色会避让播放器。
- 星星按钮打开陪伴设置，可安静陪伴、复位或隐藏。收起后点小圆钮展开，隐藏后从页脚「亚托莉」恢复。
- 手机首次访问默认收起。偏好按部署路径保存在浏览器；存储不可用时当前会话仍可用。

角色、外观面板和播放器都沿用持久节点。站内换页关闭弹窗、清理临时气泡和动画；支持 Esc、焦点恢复与弹窗互斥。轻量形象只在互动或实际音乐播放时动作，后台、安静模式、系统减少动作时停止。Web Animations API 不可用时保留文字回应。

## 可选 Live2D

星星设置或页脚「亚托莉」中打开「Live2D 亚托莉」。首次访问默认使用轻量形象，开启偏好按部署路径保存。仅宽于 640px、角色展开、页面可见、未开启安静陪伴和系统减少动作时创建渲染容器。收起、隐藏、后台或窄屏时移除整个 iframe，取消加载中的资源、动画帧及 WebGL 上下文；恢复时使用浏览器缓存重新创建。站内切页持久化同一个容器，不创建第二个角色。

参考 [Firefly Pio 文档](https://docs-firefly.cuteleaf.cn/zh/guide/pio.html)，采用其 `l2d-widget` 的底层 [l2d 2.1.1](https://github.com/hacxy/l2d) 引擎，并复用本站工具栏，不增加独立菜单、远程图标或轮播台词。引擎只有隔离页 `companion/atri/` 引用；主页面不预加载渲染脚本和模型。该工具页不进入 sitemap、不接入访问统计。模型静音，不包含语音，保留全站唯一 audio。

实际模型为 Cubism `.model3.json` / `.moc3`，默认眨眼、呼吸、物理效果；鼠标移动通过参数驱动头部和眼球跟随，戳一戳、摸摸头使用嘴型、脸颊及微笑参数，再恢复默认状态。此素材没有动作或表情文件，不声称存在完整 motion 包。父子消息校验 origin 和 source，只开放有限控制；20 秒加载超时及模块失败会回退到轻量形象，不自动重试。关闭再开启可手动重试。

模型取自 [luckykeeper/live2d_ver3.0 固定版本](https://github.com/luckykeeper/live2d_ver3.0/tree/de3b58434160a6f224ea45cdb68c98fac297cb60/ATRI)，上游署名为 [丛雨-ムラサメ](https://space.bilibili.com/12351533)。5 个运行文件合计 3,506,574 B，采用固定版本外部加载；没有将模型、PSD、CMO3 或音频复制到本站仓库。上游未提供明确的模型再分发许可，不能把公开下载、署名或代码 MIT 当作模型授权。模型权利归各权利人；维护时可使用有明确许可的自有地址替换 `src/config/companion.ts` 中路径。

`l2d` 的 MIT 和 Cubism SDK/Core 的专有条款分别适用，见 `public/licenses/live2d.txt` 和 [Live2D 官方协议](https://www.live2d.com/eula/live2d-proprietary-software-license-agreement_en.html)。不同时引入 Spine，避免重复引擎开销。

头像采用用户 2026-11-28 提供的原图，保留完整画面缩至 384×614 WebP（37,570 B），展示时以 CSS 对准脸部。顶栏、侧栏和关于页共用一份缓存资源；自定义导航 Logo 仍可覆盖个人头像。

## 素材来源

亚托莉图来自此前核对的 [ATRI 动画官方小游戏](https://atri-anime.com/special/adventure/) 的 [透明 SD 图](https://atri-anime.com/assets/img/special/adventure/header/header_atri.png)，经缩放与透明留白整理编码为本地 WebP，20,922 字节。角色权利归原权利人，不表示官方合作或商业授权。本站鼓励台词为原创，不冒充原作对白。

轻量形象沿用既有素材，没有重新绘制该角色，三个展示入口共用同一缓存资源；可选 Live2D 的外部加载与来源另见上文。

## 维护边界

- `companions.json`：只含 `atri`，构建成品检查会拒绝其他 id。
- `companion-state.ts`：数据与偏好验证、旧 id 回退、位置与播放器避让。
- `companion-reactions.ts` / `companion-motion.ts`：有限关键帧、连击与取消；粒子最多 12 个，不叠加旧批次。
- `companion.ts`：一个持久控制器，位置只在拖动、尺寸变化和复位时更新。
- `live2d-frame.ts`：按可见条件挂载、去重、销毁和错误回退；拒绝旧容器消息，无自动重试循环。
- `companion/atri.astro` / `atri-live2d.ts`：独立渲染上下文，固定模型来源，有限参数交互，不访问聊天服务。
- `Companion.astro`：角色、收起按钮与陪伴设置；无脚本时隐藏挂件，保留正文访问。
- 测试覆盖唯一角色、损坏偏好、旧角色迁移、动作取消、减少动作与窄屏避让；成品检查逐页验证资源路径与唯一实例。

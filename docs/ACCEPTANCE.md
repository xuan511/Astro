## 建议自行测试

1. `npm ci`，再 `npm run dev`，打开终端显示的网址。
2. 在首页切换主题，打开技术、生活、项目、音乐和关于页面；手机展开菜单并跳转，确认页面与焦点清晰。
3. 在技术示例中复制 C 代码，粘贴到临时文本文件；点击中文目录，查看定位与顶部阅读进度。确认公式、表格、引用与高亮正常。
4. 在音乐页手动播放，切换到文章，后退/前进。拖动滑块、调整音量，尝试三种模式。刷新后确认没有自动播放，再手动播放检查进度恢复。
5. 搜索 Linux、调试等词，切换范围，再搜一个不存在的词，确认结果和空状态。
6. 新建一份草稿，构建后确认首页、搜索、RSS 中没有它；改为公开、更新日期后重新构建。使用真实照片测试相对路径与图片替代文本。
7. 执行 `npm run check`、`npm run format:check`、`npm test`、`npm run build`、`npm run test:built`。
8. 将完整源码推入自己的博客仓库，在 Pages 中选择 GitHub Actions，等待实际工作流成功。部署后检查项目子路径、直接打开文章链接、404、RSS 与站内音乐。
9. 在 GitHub Actions 手动运行 Lighthouse audit，查看三个页面的多次手机模拟报告，再根据实测继续优化。

进一步维护方法见 [写作指南](WRITING.md)、[音乐管理](MUSIC.md)、[部署说明](DEPLOYMENT.md)。
